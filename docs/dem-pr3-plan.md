# PR 3計画: GSI由来ではない地域DEM

調査日: 2026-10-17。**計画のみ。Provider追加、原データの大規模ダウンロード・変換・配信は未実施。**

## 調査で分かったこと

Issue #7の「GSI配信を使わない」と「GSI由来の原資料を使わない」を分け、PR 3は後者を対象にする。
全国の統合DEMはGSIを混ぜるため使わず、地域別ソースを明示して検証する。

| 候補 | 確認した由来・形式・座標系 | 条件と未確認事項 |
| --- | --- | --- |
| 兵庫県 全域DEM（2010〜2018年度） | 県・近畿地方整備局六甲砂防事務所の航空レーザー由来、地物を除去した1m格子のXYZテキスト。測地成果2000・平面直角座標系第V系。GSI DEMの再配信とは説明されていない | CKANのlicense欄は「独自利用規約」、本文にはCC BY 4.0表示がある。個別条件優先の注記あり。鉛直基準・各図郭の測量年・混合原資料の有無は製品仕様で確認が必要 |
| 兵庫県 0.5m DEM（2021〜2022年度） | 県の航空レーザー由来の地表面DEM。産総研/全国Q地図による派生配信あり | 1m版の座標系・条件を流用しない。対象地域、原成果、0.5mデータ個別条件、鉛直基準は別途確認 |
| VIRTUAL SHIZUOKA 富士山南東部・伊豆東部 | レーザー点群とLPグリッドを公開。LASをZIP/7zで提供する説明。日本測地系2011・平面直角座標系第VIII系 | CKAN本文でCC BY 4.0/ODbLのデュアルライセンス。平均約300MB、最大5.2GBの記載。0.5m格子が全地域にあるとは確定しない。地表分類・実グリッド間隔・鉛直基準を個別確認 |

由来の確認は提供者の記載に基づく。基準点・測地基準にGSIが関わることと、GSIの標高DEMを原資料に使うことは区別する。
未調査の図郭まで非GSI由来と断言しない。

## 大規模変換より先に試す経路

産総研の公式入口では2026-06にシームレス標高タイルv2が正式公開されている。
旧v1だけを前提に計画しない。v2には512px WebPとTerrarium変換エンドポイントがある。
標準WebPはTerrariumとは限らないため、形式名だけで既存decoderを選ばない。

| 候補ソースID | 公式に記載された最大ズーム | 提供範囲の外枠（west,south,east,north） |
| --- | --- | --- |
| `hyogodem`（1m DEM） | 16 | `[134.24587,34.14648,135.47185,35.67539]` |
| `hyogo2`（0.5m DEM） | 17 | 同上。県全域の0.5m実データを保証しない |
| `shizuoka` | 17 | `[137.473002,34.5721723,139.179563,35.6460457]` |

候補URL: `https://gbank.gsj.jp/seamless/elev2/terrarium/{sourceID}/{z}/{x}/{y}.webp`。
まず1mの`hyogodem`で県内の小領域を試す。DSMの`hyogodsm`、GSIを含む`mixed`は採用しない。
産総研配信はCC BY 4.0互換の利用条件に加え、原データ提供者の規定も適用される。
再配布まで許可されたと推測せず、原資料・変換成果・配信の各段階で条件を確認する。

## 実装順序と採用ゲート

1. **出典台帳を作る**: 製品ID、図郭、提供者、原成果、測量年、ライセンス本文・版・URL、必須帰属、水平/鉛直基準、欠測値、範囲を記録する。CKANメタデータと製品仕様が矛盾すれば採用を止め、未確認と記載する。
2. **既存配信を少量検証**: 神戸・北野周辺の約1km四方を試験候補とし、実カバレッジ内で300〜500mの坂を1本固定する。実タイル・CORS・512px・RGB・alpha・画素の基準位置・高さ基準を確認する。欠測部にGSIを混ぜていないことをソース別仕様で確認する。
3. **Providerを追加**: ID `aist-hyogo-dem`、z16/512px、Terrarium、フォールバックなし、出典・条件・範囲を登録する。現行の共通ローダーを再利用する。画素基準が中心と異なる場合に限り`pixelReference`設定を追加し、補間と境界を検証する。旧v1は左上端基準・256px・URLがz/y/xであり、同一視しない。
4. **地域内で比較**: GSI / Mapterhorn / 兵庫DEMを同一座標、5/10/20m、最大400点で比較する。測量時期・鉛直基準差をメモし、範囲外をGSIで埋めない。東京の既存2ルートは地域DEMの精度比較には使わない。
5. **自前配信が必要な場合だけ別工程**: 許可と容量見積りを済ませて最小図郭を取得する。DEMなら地表面・欠測・軸順・CRSを確認しGeoTIFF化、点群なら地表分類点のみを使う。EPSG:3857へ再投影し、欠測alphaを保持したlossless Terrarium 512px XYZタイルを生成する。元CRS、鉛直基準、変換コマンド、チェックサムを保存する。静的ホストでCORSとキャッシュを設定する。PMTilesは容量・要求数が必要性を示した場合の別改善とする。

受け入れ条件: 原資料の非GSI由来と利用条件が図郭単位で確認済み、少量実通信・RGB保持・境界・範囲外テストが成功、地域の同条件比較と帰属が記録済み。
原資料へ到達できない／規約・鉛直基準を確定できない場合は、その部分を未検証として止める。

今回の調査ではカタログ・仕様までを確認し、地域タイルの実通信や元LAS/XYZの内容、再配布手続きまでは検証していない。
